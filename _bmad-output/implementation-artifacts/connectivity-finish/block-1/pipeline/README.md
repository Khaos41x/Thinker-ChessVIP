# Recommendation pipeline integration evidence

Run: `node tests/test_recommendation_pipeline_chrome.js`.

The test starts its own Flask fixture and real Komodo process. It extracts the current production `request_move`, move-authority checks, arrow renderer, console swatch input handler and accepted External Config color synchronization branch. Chromium sends real HTTP requests to a test-only adapter; that adapter calls the actual Flask `/getmove` route with a valid fixture capability token and its required Chess.com origin. The opening-book lookup is disabled only inside this isolated process so initial white/black positions require actual native-engine computation. Subsequent requests may use the production legal-move cache. No production route, authorization rule, gameplay method or shared preference is changed.

The 256-case matrix covers both player identities, both board orientations and all combinations of Bot, Auto Moves, Evaluation Bar, Banner, Recent Form and Smart Pacing flags. For an authorized current position, Bot on / Auto Moves off draws the actual SVG; Auto Moves on takes the existing scheduling branch and removes arrows. The test substitutes a non-executing scheduling recorder, so it never performs a chess move. Bot off and opponent turn produce no request/arrow. Position transitions and browser reload also restore recommendations. Real DOM assertions check the SVG rectangle equals its board, color, opacity 0.8, visibility, layer 11 and pointer-events none. The actual console swatch input and accepted external color hook update visible paths immediately.

This is an isolated Chromium regression, not authenticated Chess.com/Tampermonkey verification. The test board exposes a synthetic game API and does not mount the banner, recent-form or evaluation layers; their flags are tested as pipeline inputs, not as live-site overlay geometry. The external color test exercises the userscript acknowledgement handler, not a real external browser window changing production settings. Screenshots are explicitly local fixtures. The installed Tampermonkey version, live-site authorization and live overlays remain unverified because this capture is isolated and is not attached to the authenticated tab.

`report.json` contains requests, real returned UCI moves, Komodo process generation, search telemetry, per-case DOM evidence and page exception list. `pipeline-white.png` and `pipeline-black.png` show actual recommendations in both orientations. The test closes the owned Flask server, native engines and Chromium instance. Successful final verification found no remaining fixture-owned Python, Node or Chrome processes.
