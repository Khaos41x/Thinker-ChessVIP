- (direction) The banner must remain a direct child of document.body and must not enter the Chess.com grid or flex layout.
- (capability) CAP-1: The banner mirrors the resolved native sidebar top and height and sits exactly 15 CSS pixels after its right edge.
- (capability) CAP-2: The banner scrolls naturally with the document without JavaScript position writes caused by scrolling.
- (constraint) Use position:absolute with document coordinates: top=sidebarRect.top+scrollY, left=sidebarRect.right+scrollX+15, height=sidebarRect.height.
- (constraint) ResizeObserver observes only the currently resolved native sidebar; window resize may schedule one coalesced measurement.
- (constraint) MutationObserver may detect sidebar replacement for SPA lifecycle but must not write banner geometry or observe global style/class mutations.
- (constraint) The banner must set transition:none for top, left, width, and height and preserve visibility rules for review, post-game, Ghost Mode, and /play/online.
- (constraint) Do not change the Thinker panel, Scout layout, menuHtml, host grid, or DOM injection topology.
- (note) Current code has no banner scroll listener; competing geometry paths include initial positioning, global body MutationObserver, ResizeObserver, resize handler, fallback, reconciliation, and watchdog recovery.
- (assumption) The banner width remains bounded by available horizontal space to the viewport edge while top and height exactly mirror the sidebar.

- (event) Preservation validation passed: every requested positioning, observer, transition, visibility, and layout-isolation requirement is represented in the spec or implementation companion.
