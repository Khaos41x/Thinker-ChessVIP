- (constraint) Inherited Smart Pacing AD-1: calibration policy is a functional core behind imperative adapters.

- (constraint) Inherited Smart Pacing AD-12, AD-13 and AD-17: behavioral boundaries and promoted parameter sets are versioned and distribution-calibrated.

- (decision) AD-1 binds calibration ownership: an offline control plane publishes immutable artifacts; the online core only validates and evaluates them, preventing runtime learning and mutable hidden state.
- (decision) AD-2 binds rating semantics: every target names a calibration scale and protocol; no bare Elo is treated as portable, preventing cross-pool false equivalence.
- (decision) AD-3 binds search controls: Depth and Nodes never vary with target Elo; time policy, Threads, Hash, MultiPV, binary, hardware envelope and concurrency are artifact invariants, preventing nonlinear confounding.
- (decision) AD-4 binds interpolation: weighted isotonic anchors plus monotone PCHIP are inverted; integral Skill is resolved by seeded adjacent-level mixture, preventing polynomial overshoot and illegal fractional UCI values.
- (decision) AD-5 binds unsupported ranges: the system never extrapolates below measured Skill 0 or above Skill 25; it rejects or explicitly degrades, preventing fabricated strength claims.
- (decision) AD-6 binds low Elo: ratings below the Skill floor use a separately calibrated human-error candidate policy with fixed search/MultiPV and deterministic seeds, preventing depth-damaged positional play.
- (decision) AD-7 binds benchmark proof: color-reversed opening pairs, fixed manifests, pentanomial statistics, confidence intervals and holdout targets govern promotion, preventing anecdotal 50-percent claims.
- (decision) AD-8 binds engine state: profiles apply atomically at game boundaries to isolated engine leases, preventing process-global UCI option races.
- (decision) AD-9 binds observability: bounded Prometheus values/counters track target, applied Skill, nodes and search seconds; high-cardinality context stays in structured logs, preventing metric-cardinality failures.
- (decision) AD-10 binds release safety: artifacts progress candidate to validated to active with checksum, engine hash, shadow/canary and rollback, preventing unreviewed calibration pushes.
- (assumption) [ASSUMPTION] Initial acceptance band is point estimate within 35 Elo and 95-percent interval contained within 75 Elo after at least 200 opening pairs; pilot variance may revise this before implementation acceptance.
- (question) The product-facing rating namespace is not yet chosen: CCRL-equivalent, Stockfish-reference-equivalent, Chess.com-bridged, or multiple explicit scales.
